# peterchen-smartwatch

To create Smart Watch for Patients, the design will have a very Compact PCB.


- Two basic sensor will be used: Heart Rate and Temperature. (Client has given these part number: MAX30102, TMP117)
- Main Controller: ESP32 (Client only wants to utilise BLE feature)
- Charging Circuit. 
- Programming Section. 
- Battery Selection. One time charge, the device need to run one week minimum. More is better. Battery will be Li-ion or you can select better chemistry for this watch.
- Input/Output: USB C
- Display: Small screen will be used, I will recommend 0.96" OLED. This display will be removed in final product. I told client to use PC display for testing/prototype purpose. But he wants to use display.
- Connectivity: Via BLE, it is connected with Smartphone.
- Size: 400 sq.mm
